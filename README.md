# Mentor Skills

A unified reference taxonomy for startup mentorship and business advisory.

## Canonical reference

- **SKILLS.md** — the master `mentor-skills` reference containing all mentor domains.
- **schemas/mentor-skill.schema.json** — machine-readable schema for future structured mentor profiles, agents, and skill registries.

## Scope

The taxonomy covers entrepreneurship, strategy, validation, market research, business models, product, UX, marketing, growth, sales, finance, accounting, audit, Iran taxation, investment, banking, fintech, warehouse and inventory, procurement, supply chain, import/export, logistics, startup law, intellectual property, compliance, risk, technology, cybersecurity, AI, data, HR, operations, branding/PR, international expansion, insurance, crisis management, and exit/M&A.

## Intended use

This repository can be used as a shared reference for:

1. Human mentor specialization and capability mapping.
2. AI startup-advisor system prompts and routing.
3. Mentor matching and competency matrices.
4. Startup diagnostic checklists.
5. Future structured skill registries and APIs.

> This taxonomy is a knowledge and capability reference. It does not replace licensed legal, tax, audit, financial, or other regulated professional advice.
