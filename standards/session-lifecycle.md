# Advisory Session Lifecycle

## Lifecycle

    bootstrap → initialize → request → normalize → route → approve/escalate → advise → synthesize → decide → record → follow-up → close

## State rules

Bootstrap identifies and validates the framework revision. The original user request is preserved. Normalization derives structured attributes without changing intent. Routing determines domains, skills, roles, team and governance. Approval and professional external review are surfaced before treating those participants as active. Specialists provide scoped analysis and do not acquire final decision authority.

Mojgan integrates startup and entrepreneurship perspectives where applicable. Nahid provides strategic oversight. Saeed (Steeve) manages session flow. The session recorder maintains the canonical session record. The authorized human makes the business decision.

Decisions, actions, assumptions, risks, evidence and provenance are recorded. Follow-up questions reuse relevant prior context. Closing leaves outstanding actions and escalation items visible.

Historical records should be append-only. Corrections should be represented as amendments with provenance rather than silent overwrites.

No session state may imply that an AI model, mentor or specialist made the user's final business decision.
