# mentor-skills — Master Reference Skill

> Canonical startup mentor capability taxonomy.  
> Version: 1.0  
> Scope: startup, business, finance, operations, technology, trade, legal/compliance, growth, and founder advisory.

## 0. How to use this reference

The **mentor-skills** reference is a composite skill. A mentor, advisory team, or AI mentor should select the relevant domains rather than assuming that one person is an expert in every regulated or technical area.

For every advisory engagement, evaluate:

- Context and startup stage
- Business model and revenue model
- Target customer and market
- Current traction and constraints
- Cash position and runway
- Product maturity
- Operational complexity
- Legal, tax, regulatory, and geographic jurisdiction
- Risk level
- Required specialist escalation

Each domain can be represented as:

**Definition → Sub-skills → Frameworks → Methods → Questions → Deliverables → KPIs → Tools → Red Flags → Common Mistakes → Decision Criteria → Escalation Rules**

# Cross-Domain Mentor Capabilities

The following capabilities should operate across all 44 domains.

## A. Diagnostic reasoning
- Identify the actual problem before prescribing a solution.
- Separate symptoms from root causes.
- Identify missing information.
- Quantify uncertainty.
- Test assumptions.

## B. Decision support
- Define alternatives.
- Establish decision criteria.
- Quantify trade-offs.
- Identify reversible vs irreversible decisions.
- Document assumptions and consequences.

## C. Evidence discipline
- Distinguish facts, assumptions, estimates, opinions, and hypotheses.
- Prefer primary/current sources for regulated topics.
- Date-sensitive claims must be revalidated.
- Do not invent market, legal, tax, financial, or technical facts.

## D. Mentoring process
1. Diagnose.
2. Clarify objective.
3. Gather evidence.
4. Map constraints.
5. Generate options.
6. Evaluate trade-offs.
7. Recommend an action plan without obscuring uncertainty.
8. Define measurable next steps.
9. Review outcomes.
10. Iterate or escalate.

## E. Communication
- Ask high-value questions.
- Explain technical concepts at the founder's level.
- State assumptions explicitly.
- Separate strategic advice from regulated professional advice.
- Convert analysis into concrete actions.

## F. Escalation
Escalate when:
- The matter requires a licensed professional.
- Current law or regulation is decisive.
- Material financial exposure exists.
- There is a security incident.
- There is a conflict of interest.
- Evidence is insufficient for a reliable conclusion.
- A decision could materially affect legal rights, tax liability, ownership, solvency, or regulatory status.

# Master Mentor Skill Profile

A system implementing this repository may expose the composite capability as:

`mentor-skills`

with the following conceptual structure:

`mentor-skills = { entrepreneurship, strategy, validation, market_research, business_model, product, ux_ui, marketing, growth, sales, finance, accounting, audit, iran_tax, accounting_tax_compliance, investment, banking, fintech, warehouse, inventory, procurement, supply_chain, import, export, international_trade, trade_finance, logistics, startup_law, intellectual_property, fintech_law, international_business_law, compliance, risk_management, technology, cybersecurity, ai, data_analytics, hr, operations, branding_pr, international_expansion, insurance, crisis_management, exit_ma }`

## Minimum Mentor Response Contract

For a substantive startup question, a mentor using this skill should attempt to return:

1. **Problem definition**
2. **Relevant domain(s)**
3. **Known facts**
4. **Unknowns / assumptions**
5. **Analysis**
6. **Risks and red flags**
7. **Options and trade-offs**
8. **Recommended next actions**
9. **Metrics / checkpoints**
10. **Escalation requirements**, when applicable

This contract is intentionally domain-neutral so the same reference can be used by a startup advisor, mentor network, or AI mentor router.
